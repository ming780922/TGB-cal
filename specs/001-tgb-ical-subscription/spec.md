# Feature Specification: TGB 籃球聯盟賽程 iCal 訂閱網站

**Feature Branch**: `001-tgb-ical-subscription`
**Created**: 2026-05-05
**Status**: Draft
**Input**: User description: "@TGB-cal.md"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 球隊賽程訂閱到行事曆 (Priority: P1)

籃球迷想要追蹤特定球隊的賽程，希望比賽時間能自動出現在他們的 Apple 或 Google 行事曆中，不需手動新增每場比賽。

**Why this priority**: 這是整個服務的核心價值。沒有訂閱功能，其他功能都失去意義。讓使用者能一鍵訂閱，比賽異動時行事曆自動更新。

**Independent Test**: 可透過以下流程獨立驗證：使用者找到球隊頁面 → 點擊「加入 Apple 行事曆」或「加入 Google 日曆」→ 行事曆 app 顯示該球隊所有已排定比賽。

**Acceptance Scenarios**:

1. **Given** 使用者在球隊頁面，**When** 點擊「加入 Apple 行事曆」按鈕，**Then** 裝置開啟 Apple 行事曆並提示訂閱該球隊賽程日曆
2. **Given** 使用者在球隊頁面，**When** 點擊「加入 Google 日曆」按鈕，**Then** 瀏覽器開啟 Google 日曆新增訂閱頁面並預填 iCal 網址
3. **Given** 使用者已訂閱，**When** TGB 官方更新賽程（更改時間、場館或比賽結果），**Then** 行事曆在下次同步後自動反映最新資訊
4. **Given** 使用者在球隊頁面，**When** 點擊「複製連結」，**Then** iCal 訂閱網址複製至剪貼簿，可貼至任何支援 iCal 的行事曆軟體

---

### User Story 2 - 搜尋並找到球隊 (Priority: P2)

使用者知道想訂閱的球隊名稱，但不知道如何在網站上找到該球隊，希望能快速透過搜尋找到並進入球隊頁面。

**Why this priority**: 若使用者找不到球隊，就無法完成訂閱。搜尋是進入球隊頁面的主要入口。

**Independent Test**: 可獨立驗證：在首頁搜尋框輸入球隊名稱（完整或部分）→ 搜尋結果即時出現 → 點擊結果進入球隊頁面。

**Acceptance Scenarios**:

1. **Given** 使用者在首頁，**When** 在搜尋框輸入球隊名稱的一部分（至少 1 個字），**Then** 符合的球隊名稱即時顯示於搜尋結果清單
2. **Given** 搜尋結果出現，**When** 使用者點擊某球隊，**Then** 導向該球隊的專屬頁面
3. **Given** 使用者搜尋不存在的球隊名稱，**When** 無符合結果，**Then** 顯示「查無此球隊」提示
4. **Given** 使用者第一次進入首頁，**When** 尚未搜尋，**Then** 顯示熱門球隊快速連結清單

---

### User Story 3 - 查看球隊賽程資訊 (Priority: P3)

使用者在訂閱前想先確認球隊目前的賽季狀態、近期比賽場次與對手，再決定是否訂閱。

**Why this priority**: 提供賽程資訊讓使用者在訂閱前能做出有依據的決定，提升訂閱意願與信任感。

**Independent Test**: 可獨立驗證：進入球隊頁面 → 看到目前賽季名稱、分組、戰績與即將到來的比賽場次。

**Acceptance Scenarios**:

1. **Given** 使用者在有進行中賽季的球隊頁面，**When** 頁面載入，**Then** 顯示聯盟名稱、分組名稱、目前戰績及比分（勝/負）、已排定場次數及下一場比賽時間與對手
2. **Given** 使用者在無進行中賽季的球隊頁面，**When** 頁面載入，**Then** 顯示最近一個已結束賽季的資訊，並以灰色「已結束」標示
3. **Given** 球隊同時參加多個聯盟，**When** 頁面載入，**Then** 所有進行中賽季皆分別列出
4. **Given** 比賽已完賽，**When** 使用者查看賽程，**Then** 已完賽場次顯示最終比分（如已抓取）

---

### Edge Cases

- 球隊名稱搜尋應支援繁體中文、英文及混合查詢
- 若 TGB 官方網站暫時無法存取，爬蟲失敗時現有資料仍正常提供，不影響訂閱服務
- 球隊尚無任何已排定場次時，球隊頁面仍可正常顯示（顯示空賽程提示）
- iCal feed 在行事曆軟體反覆同步時，已完賽比賽的資料不應被覆蓋為「待確認」狀態
- 使用者可能在不支援 webcal:// 協定的環境下訪問，此時應仍能複製 https:// 連結手動新增

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系統 MUST 為每支球隊提供一個唯一的 iCal feed 網址，可直接被 Apple 行事曆、Google 日曆等標準行事曆軟體訂閱
- **FR-002**: 系統 MUST 在每份 iCal feed 中包含該球隊所有已排定及已完賽的比賽場次
- **FR-003**: 每場比賽 MUST 包含：比賽時間、主客隊名稱、場館名稱與地址、所屬聯盟與分組資訊、TGB 官方比賽頁面連結
- **FR-004**: 已完賽比賽 MUST 在 iCal 標題中顯示最終比分
- **FR-005**: 當比賽資訊（時間、場館、對手）異動時，iCal feed MUST 反映最新資訊，並透過版本號遞增通知行事曆軟體更新
- **FR-006**: 系統 MUST 每日自動從 TGB 官方網站爬取最新賽程資料
- **FR-007**: 系統 MUST 提供球隊名稱搜尋功能，支援即時搜尋（使用者輸入時即時回傳結果）
- **FR-008**: 系統 MUST 為每支球隊提供獨立的球隊頁面，展示賽季資訊與訂閱入口
- **FR-009**: 系統 MUST 同時支援繁體中文（zh）與英文（en）介面
- **FR-010**: 系統 MUST 支援 HTTP 條件式請求，避免行事曆軟體頻繁下載未更新的 feed
- **FR-011**: 球隊頁面 MUST 提供三種訂閱方式：直接加入 Apple 行事曆、加入 Google 日曆、複製 iCal 連結
- **FR-012**: 系統 MUST 自動產生 sitemap.xml 涵蓋所有球隊的中英文頁面，供搜尋引擎索引
- **FR-013**: 網站 MUST 包含使用者條款與隱私權政策頁面，聲明資料來源、免責事項及不收集個人資料

### Key Entities

- **League（聯盟）**: 代表 TGB 的一個賽事系列，跨賽季穩定存在，以唯一識別碼（gid）區分；含場地區域、活動日、性別、賽事類型屬性
- **Division（分組）**: 特定賽季中某聯盟的特定組別，以 level_id 識別；含賽季標籤、分組標籤、完整名稱、首末場時間、球隊數量
- **Team（球隊）**: 以 tid 識別的球隊，可跨賽季、跨聯盟參賽；含標準化名稱（用於搜尋）、最後比賽時間、活躍分組數量
- **Game（比賽）**: 一場具體的比賽；含主客隊、時間（UTC 與本地時間）、場館、比分、狀態（已排定/已完賽/延期/取消），每場比賽有全域唯一識別碼供 iCal 使用
- **iCal Feed**: 每支球隊對應一個動態產生的日曆訂閱檔案，含快取資訊（etag、最後修改時間）以支援 HTTP 條件式請求

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 使用者從首頁搜尋到找到目標球隊頁面的操作步驟不超過 3 步
- **SC-002**: 球隊頁面的訂閱按鈕點擊後，行事曆 app 或頁面可在 2 秒內開始回應
- **SC-003**: iCal feed 中每場比賽的時間、場館、對手資訊正確率達 100%（以 TGB 官方網站當下資料為準）
- **SC-004**: 賽程更新後，最多 25 小時內（下次每日爬蟲執行後）行事曆訂閱者可取得最新資訊
- **SC-005**: 使用者可在 5 分鐘內完成從首次造訪到成功訂閱的完整流程
- **SC-006**: 搜尋回應時間在正常網路環境下不超過 500 毫秒
- **SC-007**: 網站對所有在資料庫中有記錄的球隊均提供可存取的球隊頁面（零漏網）

## Assumptions

- 目標使用者主要為 TGB 聯盟的球員與球迷，熟悉行事曆軟體的訂閱功能
- TGB 官方網站（tgbleague.com）的 HTML 結構在本專案開發期間保持穩定，爬蟲可正常解析
- 使用者裝置已安裝 Apple 行事曆（iOS/macOS）或可使用 Google 日曆網頁版
- 網站不提供使用者帳號或登入功能，所有訂閱連結均為公開網址
- 賽程資料版權屬 TGB 官方所有，本網站為便民工具，非商業用途，應於條款中聲明
- 場館名稱由爬蟲取得，地址由系統內建對照表提供（需人工確認正確性後填入）
- 行動裝置為主要使用情境，網站介面應以行動優先設計
- iCal 訂閱連結使用 https:// 協定（Apple 行事曆另提供 webcal:// 捷徑方式）
